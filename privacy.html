Privacy Policy

Last updated: October 19, 2026

Obsidian Bioinformatics Sync is a personal tool intended to organize bioinformatics study notes and synchronize them with Google Drive for use in Obsidian.

Data Access

The application may request access to Google Drive files as authorized by the user, for the purpose of storing, retrieving, and synchronizing study notes.

Data Use and Storage

Authorized data is used only for note synchronization. Notes may be stored in the user's Google Drive and local Obsidian vault. The application does not sell user data or use it for advertising.

Data Sharing

The application does not share Google user data with third parties except as necessary to provide the requested synchronization functionality.

Data Retention and Deletion

Users can delete synchronized notes from Google Drive and their local Obsidian vault. Users can revoke the application's Google account access through their Google Account security settings.

Security

The application is intended to use Google's OAuth authorization mechanism. Access credentials must be handled securely and must not be published in the public GitHub repository.

Contact

For privacy inquiries, please contact the application owner through the project's GitHub repository.
